## 2024-10-23 - Secure Navigation and External Protocol Execution
**Vulnerability:** The Electron app allowed arbitrary navigation and uncensored shell.openExternal execution because webSecurity was disabled to support mixed content streaming, but window/navigation event handlers and IPC inputs were missing proper URL validation.
**Learning:** In Electron apps where webSecurity is false, standard web navigation constraints are bypassed. An attacker who can control an external link or iframe could trigger app navigation to an untrusted site, or execute arbitrary local URI schemes (e.g., file://, ms-msdt://) leading to code execution.
**Prevention:** Always implement setWindowOpenHandler and will-navigate listeners to strictly allowlist protocols (like file: and localhost) for internal app navigation. When using shell.openExternal via IPC, explicitly restrict allowed protocols to http: and https: and wrap URL parsing in try-catch blocks to prevent malformed URL crashes.
