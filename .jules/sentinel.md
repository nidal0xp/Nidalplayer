## 2024-05-24 - Missing Navigation Security Controls
**Vulnerability:** The Electron app allows uncontrolled navigation and window opening because it lacks `will-navigate` and `setWindowOpenHandler` event listeners on `mainWindow.webContents`. Additionally, the IPC handler for `open-external` allows arbitrary URLs to be passed to `shell.openExternal`.
**Learning:** This exposes the app to unintended navigations (e.g., leaving the local file context) or potentially executing malicious URLs via `open-external`. The memory explicitly states to secure `will-navigate` in Electron applications that use `loadFile()`, explicitly allowing the `file:` protocol and local development hosts (`localhost`, `127.0.0.1`).
**Prevention:** Always implement `will-navigate` and `setWindowOpenHandler` to validate destination URLs. For `will-navigate`, ensure it stays on `file://` or `http://127.0.0.1` / `http://localhost`. For `setWindowOpenHandler` and `open-external`, validate that the URL protocol is safe (e.g. `http:` or `https:`) before proceeding.
