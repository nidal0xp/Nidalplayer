## 2026-10-12 - [App Accessibility: Icon-Only Buttons]
 **Learning:** [The application uses numerous raw text symbols (e.g., '★', '⛶') for icon-only action buttons. Without explicit labels, these provide no context to screen readers, severely impacting accessibility.]
 **Action:** [Always ensure that any newly added icon-only `<button>` or interactive element is accompanied by a descriptive `aria-label` attribute.]
