## 2026-10-10 - [Add ARIA labels to HUD icon-only buttons]
**Learning:** [The application's custom modals and icon-only UI elements like the HUD player controls often rely purely on raw text symbols (e.g., '⏮', '▶', '▣') lacking default semantics, necessitating the manual addition of `aria-label` attributes for proper screen reader accessibility.]
**Action:** [When working with icon-only interactive elements, explicitly assign `aria-label` or `aria-hidden` for visual-only elements to ensure keyboard and screen reader accessibility is maintained.]
